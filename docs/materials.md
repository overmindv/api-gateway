# Материалы в GraphQL

Все операции требуют сессию. Gateway передает Content только ID
подтвержденного пользователя, сервисный токен и допустимый ID запроса.
Роли, JWT и пользовательские заголовки авторизации не передаются.

- `materials(filter, limit, cursor)`: каталог с фильтром по теме, автору
  или статусу. `nextCursor: null` означает конец.
- `material(id)`: текст текущей рабочей ревизии для владельца или
  опубликованной для остальных. Чужой черновик выглядит как отсутствующая
  запись.
- `publishedMaterial(id)`: только опубликованная ревизия для любого
  вошедшего пользователя, даже владельца. Черновой, архивный или скрытый
  материал возвращается как `NOT_FOUND`. В Apollo запрашивай это поле
  с `fetchPolicy: "no-cache"`, чтобы не смешивать его с редактором.
- `materialRevisions(id, limit, beforeRevision)`: история для владельца
  без текста ревизий. Для следующей страницы передай `nextBeforeRevision`.
- `createMaterialDraft(input)`: новый материал с текстом, вложениями
  и учебными полями.
- `saveMaterialDraft(input)`: новая рабочая ревизия. Передай
  `expectedRevisionId` из прочитанного материала. Поле `attachments`
  можно опустить для сохранения списка или передать `[]` для очистки.
- `publishMaterial(id, expectedRevisionId)`: публикация допустимой
  ревизии. Первую публикацию делает владелец. Правки к опубликованному
  материалу идут через ревью.

Страница по умолчанию содержит до 20 записей, максимум 50.
Если поле завершается ошибкой, оно возвращается как `null`, а другие
поля операции могут сохранить результат. Клиенту доступны
`UNAUTHENTICATED`, `NOT_FOUND`, `INVALID_ARGUMENT`, `REVISION_CONFLICT`,
`FAILED_PRECONDITION`, `DEADLINE_EXCEEDED` и `SERVICE_UNAVAILABLE`.
После `REVISION_CONFLICT` перечитай материал перед повтором операции.

Для включения укажи `CONTENT_GRPC_ADDR` в формате `host:port` и отдельный
`CONTENT_GRPC_SERVICE_TOKEN` от 32 до 256 печатных ASCII-символов без
пробелов, совпадающий с токеном Content. Дедлайн
`CONTENT_GRPC_TIMEOUT` по умолчанию 3 с, максимум 10 с. Gateway проверяет
сертификат TLS. Для локального Compose, где Content слушает без TLS,
используй `CONTENT_GRPC_INSECURE=true`. В production эта настройка запрещена.
