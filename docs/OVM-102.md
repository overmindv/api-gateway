# OVM-102 — режимы программных решений в GraphQL

`ITCodeRunMode = samples | graded`; input `runMode` имеет default samples,
output `ITCodeSubmission.runMode` присутствует в mutation, polling и history.
Client передаёт REST multipart `run_mode` явно. Lifecycle остаётся queued/completed,
executionId указывает текущую попытку. Новых бизнес-состояний gateway не вычисляет.

Graded выдаёт verdict, идентификаторы и суммарные метрики, но не список кейсов.
Даже если tasks ошибочно вернёт hidden stdout/ID, GraphQL его не публикует.
Phase stdout/stderr всегда пусты; failure code ограничен allowlist, message фиксирован.
Samples показывает только канонические open-N кейсы. Неизвестный upstream режим
обрабатывается консервативно как graded без case payload. Отсутствующий legacy
режим отображается samples. Private suite/source/expected fields не входят в DTO.

PracticePlan отправляет рекомендателю только явно graded code results; samples
и legacy без режима не считаются учебным результатом. Выборочные решения не меняются.
Frontend может передать runMode, но UI-переключатель требует отдельной задачи.

Зависимость rollout: сначала tasks с OVM-244, затем gateway; новый gateway всегда
посылает run_mode, старый tasks его отклонит. Не удалять runtime старых suite.
Ранее подготовленный локальный gateway commit 4afefd0 сохранён в другой ветке.

Проверки: GraphQL handler → REST client → httptest upstream для режимов/default,
mutation/polling/history, rejection unknown enum, приватные canaries и evidence;
unit/race, lint, build, vet; make generate с preserve_resolver. Локальный gqlgen
требует GOTOOLCHAIN=go1.25.0 (go.mod); host Go1.27 вызывает type loader error.
Полный live стек/gojudge и UI/browser в этом срезе не запускались.
